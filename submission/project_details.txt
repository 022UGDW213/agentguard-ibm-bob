AgentGuard is a model-agnostic security harness for AI agents that fixes the confused-deputy problem: every tool call passes through a deny-by-default policy engine honoring only HMAC-signed, scoped capability tokens; every decision audited. It also scans codebases for secrets and vulnerable dependencies via pip-audit and npm audit. Built for Theme 1 (Students / Early Career — Explore, Fix, and Build), it integrates IBM Bob two ways: Bob consumes AgentGuard as an MCP server (check_policy, scan_codebase, audit_summary), and AgentGuard governs Bob-driven agent loops via the Bob Shell CLI. Stack: Python, MCP SDK, IBM Bob, Docker. 28 tests pass; no mocks, no stubs.
